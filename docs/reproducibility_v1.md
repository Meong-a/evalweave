# 复现说明 v1

## 必须固定

- 模型权重或服务端模型版本
- Adapter 权重
- 数据文件及切分
- Prompt 模板
- 答案解析器版本
- 生成参数
- 随机种子
- 依赖环境

## 自动记录

运行目录保存：

- 展开后的完整配置
- 数据、配置和 Prompt 哈希
- Python、操作系统和关键包版本
- 每题原始输出及解析结果
- 单题指标和汇总指标

## 推荐复现流程

1. 核对 `hashes_v1.json`。
2. 核对 `environment_v1.json`。
3. 使用相同实验配置重新运行。
4. 从 `predictions_v1.jsonl` 独立复算指标。
5. 如果输出不同，优先检查模型版本、服务端版本和 GPU 非确定性。
